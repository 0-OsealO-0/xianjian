### 我需要写的代码（你授权后我一口气做完）

| 文件 | 要做什么 | 关键决策 |
|---|---|---|
| `workers/src/index.js` | 用 `fetch(request, env)` 复刻 `api.mjs` 的全部接口 | 路由表照搬：`/api/{register,login,logout,me,consent,feedback,stats,admin/feedback,search}` |
| 同文件 `db` 层 | `env.DB.prepare(...).bind(...).run()/first()/all()` | D1 就是 SQLite，SQL 与 `store.mjs` 几乎逐字相同 |
| 密码哈希 | **PBKDF2-SHA256（10 万次）** 替代 `scryptSync` | Workers 运行时没有 scrypt；PBKDF2 有 WebCrypto 原生支持，存 `salt` 与 `hash` 两个字段不变 |
| B 站 wbi 签名 | 自带一份 **纯 JS md5**（约 60 行） | WebCrypto 不提供 md5；签名逻辑照抄 `server.mjs` 的 `signWbi()` |
| Cookie | 同名 `xj_sid`，`HttpOnly; SameSite=Lax; Secure`（Workers 一律 https） | 与本地一致，前端零改动 |
| 前端 | 只改 `account.js` 的 baseURL（`location.origin` 已是 Workers 域名，实际不用改） | 静态资源由 `[assets]` 直出，路径不变 |
