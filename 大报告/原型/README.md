# 先见 · 方向先行的学习引擎（原型 v0.3.1）

> 先看清楚这个专业在忙什么，再决定学什么。
> 单文件静态原型，双击 `index.html` 就能用；数据只存在浏览器本地（`localStorage`）。

---

## 一、这一版修的五件事

| 你提的问题 | 现在的做法 |
| --- | --- |
| 勾了知识点，课程那行还写"未开始" | 课程头改成三态汇总：`学过 1` / `在学 1` / `还没开始`；勾一次是"在学"，再勾是"学过"，再点是"没学"，标题跟着即时变 |
| 学校和专业选择不见了，专业又不影响内容 | 恢复两个下拉。**专业驱动课程表与方向地图**：电子信息类 17 门课 / 6 条路；计算机类 12 门课 / 3 条路；其他专业先给 4 条跨学科的路。换专业会重新算课程表，已选方向若不属于新专业会自动作废 |
| 一上来就问"最想明白的"太突兀 | 删掉。现在是：选专业 → **专业介绍页**（它在啃的三类硬问题 / 走出校门后长成的样子 / 一个常见误解）→ 再进方向地图 |
| 想提自己的创新 idea | 专业介绍页底部有一个「你也可以带着自己的问题来」。走完一条路回到总结页，会把它作为**第 1 版**摆出来，问你"它该改哪里"，存成第 2 版（版本链） |
| 长文稿没有入口 | 首页与方向地图底部都有「这份东西为什么长这样」→ 一页简短解释（四条不妥协的地方）+「打开完整长文稿 ↗」指向 `项目构想_先见_v0.md`（已复制进 `原型/`，静态与本地服务都能打开） |
| 点步骤条会跳转错乱 | 每个入口加前置校验：第 1 步（没有方向时）落专业介绍、有方向落地图；第 2 步落知识点页；第 3 步没方向就回专业介绍，绝不进空白页 |

**v0.4c 补的：本机服务（就地搜 B 站候选）**

静态双击打开也能用，只是「就地搜」那一行会提示你去起服务。起服务之后，任务页会多一个按钮：**在 B 站找 3 个候选**，就地显示标题、作者、时长、播放量，一键「收进我的清单」（存在 `我的进度 → 我收下的课`）。

```
双击 大报告/启动服务.cmd      ← Windows 最简单
或  node 服务/server.mjs      ← 任意系统
然后浏览器打开 http://127.0.0.1:8787/
```

- 服务只监听 `127.0.0.1:8787`，零依赖（只用 Node 内置模块），不联网到除 B 站以外的任何地方。
- 搜索走 B 站 `search/type` 接口，带 wbi 签名（`w_rid` + `wts`）与访客 cookie（`buvid3`），结果缓存 24 小时。
- 拿了 cookie 才拿得到 `buvid3`；**没有登录态**，所以结果和你在浏览器里搜的略有差别（少了个人化，反而更干净）。
- 频率别太高：脚本里没有做请求间隔控制，短时间连点可能被 B 站风控（返回 `code!==0`，页面会提示「接口不可用」并退回搜索入口）。

**v0.4b 补的：人工策展的课程白名单（B 站直达）**
- 新增 `COURSES_DB`（在 `data.js` 末尾）：**17 门课、17 条直达链接**，每条都有「谁讲的」「看它解决什么」「不要怎么用」。
  - 数学：3Blue1Brown《线性代数的本质》《微积分的本质》、MIT 18.06（Gilbert Strang）、宋浩《概率论与数理统计》
  - 语言：翁恺 C 语言（浙大）、嵩天 Python（北理工）、郭彦甫 MATLAB（台大）；C++/Java 因质量差异大，给的是精准搜索 + 「先看前十分钟再决定跟哪个」的用法
  - 计算机：王道数据结构、CMU 15-213（CSAPP）、哈工大操作系统（李治军）、中科大《计算机网络：自顶向下方法》（郑烇）
  - 电子：郑君里《信号与系统》、张锦皓《通信原理》、清华《模拟电子技术基础》（华成英）
  - AI：李宏毅机器学习（国语授权版）
- 任务页「去哪学」里，**人工筛过的**排在最上面（标题 + 来源 + 一句用法），下面才是搜索入口（B 站 / MOOC / 官方文档 / GitHub）。
- 用法一句话写在每条里，比如 18.06 是「卡在为什么的时候看一讲，不用从头刷完」，袁术课是「只挑这一步对应的那一节」——防止学生把白名单当成「必须刷完」。
- **维护**：链接会旧（视频下架、UP 改名）。每学期手动过一遍 `COURSES_DB`，失效的换掉或降级成 `kind:"search"`。这是「人工策展」的代价，也是它比自动搜索准的原因。

**v0.4 补的：去哪学 + AI 老师**
- 每件任务下面多一张「去哪学（这一步的）」：**看视频**（B 站搜索，按播放量排 / 中国大学 MOOC）、**读文档**（官方文档直链：Python 教程、NumPy quickstart、pandas 10min、cppreference、MDN、MATLAB、dev.java…）、**抄代码**（GitHub 搜可运行的例子仓库）。
- 关键词是**按知识点/按步骤**写的（`SRC`、`STEP_SRC` 两张表），不是把任务标题丢进搜索框。
- **找老师**：一键生成一段可直接粘进 ChatGPT / DeepSeek 的提示词，里面已经写清「这一步要做什么、你已学过哪些、要它只讲够用的那一点、并出三个自检问题」。
- 为什么不做「硬编码视频链接」：链接会失效、也可能挂羊头卖狗肉；平台侧 API 有签名与风控（B 站 wbi），静态页面也拿不到跨域数据。所以这一版给的是**可靠的搜索入口 + 精确关键词**。

**v0.3.3 补的：留痕 + 计算机类写厚**
- 动手类任务（`do` 与 `learn`）下面多一张「留痕（可以不写）」：写过的几行代码、跑出来的数字、截图里看到的东西。**不打分、不上传**，只存在本地，进度页会列出来（`你留下的痕迹`）。
- 计算机类三条方向从 3 步补到 4 步，密度对齐电子信息类：系统与网络加「跑 ping / traceroute 把延迟拆到每一跳」；机器学习加「手写一步梯度下降再和框架对」；图形与交互加「采样点从 10 加到 200 比较观感」。
- 这三步都带 `req`，所以会把 `分层与 TCP`、`导数与微分`、`NumPy 与画图` 这些地基**自动插进任务链**——编程语言与数学不再是独立菜单，而是被任务拉进来的。
- 试用材料在 `../试用/试用说明_给同学.md`（10 分钟脚本 + 四个问题）。

**v0.3.1 补的：语言路线**
- 专业介绍页多一张「这个专业的编程语言路线」：时间是排好的一条线，不是一张表。
  - 电子信息类：C（大一）→ Python（大一下）→ C++（大二）→ MATLAB（大二）
  - 计算机类：C → C++ → Python → Java
  - 其他专业：Python 先行，C / C++ / MATLAB 标"看方向再补"
- 每门语言都有「为什么学它」和「第一件做什么」，并且**本身就是带知识点的课**（**C 4 块**：语法流程与函数 / 指针与数组 / 动态内存与常见错误 / 结构体·链表与文件；**C++ 4 块**：类与对象 / 模板与 STL / 内存与 RAII / 编译与工程组织；**Python 5 块**：语法容器 / NumPy 与画图 / 读文件 / pandas 分组统计 / 调模型库；**MATLAB 3 块**：矩阵与绘图 / 信号仿真 / 滤波器设计；**Java 4 块**：面向对象 / 集合与泛型 / 多线程 / 构建与测试），在第 2 步里能勾"学过/在学"，勾过之后任务链会自动跳过。
- 语言已经接进任务链：计算机类的"机器学习入门"要求 `NumPy 与画图`，没学过就会先插一条"补一块地基：NumPy 与画图"。

另外：新增「如果你对其他专业的方向也感兴趣」区（AI + 医疗影像 / 金融风控 / 教育 / 智能制造），任何专业都能选；侧栏高亮归属也修了（专业介绍页不再错误高亮第 3 步）。

## 二、走一遍是什么感觉

1. 打开 → 选学校、专业（默认东南大学 / 电子信息类）、年级、每周时长
2. 「先看看这个专业」→ 读到这个专业的三类硬问题与六种去向，可以顺手写下自己的问题
3. 「看看有哪些方向」→ 六张方向卡 + 四条跨学科的路；`矩阵到底用来干什么` 三个折叠页仍在
4. 选一条（比如通信与网络）→ 被问「你学到哪了」，按**知识点**勾（极限与连续：在学 → 学过）
5. 「看我的计划」→ 一句话目标 + 「一共 5 件，大约 5 天」+ 只有第一件
6. 做完 → 被追问一句 → 反馈 + 「你刚刚拿到了 X」+ 下一件
7. 下一件有时是**补一块地基**（比如"随机变量与分布"）——因为后面那一步要用它；补完，它自己从队列里消失
8. 走完 → 总结页列出这一趟做的事 + **回到你带来的问题，改一版**

## 四、数据怎么改

- **换一个专业的结果**：只改 `data.js`（COURSES / DIRECTIONS / FIX）与 `majors.js`（MAJOR_LIST 里的 `courses()` / `directions()` / 三块介绍文案）。
- **改语言路线**：`majors.js` 的 `LANG_COURSES`（语言课与知识点）与 `LANG_PATHS`（每个专业的顺序、why、第一件）。
- **改一条路的任务链**：`DIRECTIONS[].steps[]`，每一步 `{k:"read"|"do"|"check", t, min, why, how[], req[], ask?{q, expect[], gap, follow}}`。
  - `req` 里的知识点没学时，队列会在这一步之前自动插一条「补一块地基」。
  - `ask.expect` 是判读关键词，命中率 ≥0.34 算接住、>0 算碰到边、0 算没对上（这一步是规则引擎，不是模型）。
- **加知识点**：`courses[].units[]` 里加 `{id,name}`，再到 `FIX` 里给它写 `{why, how[3]}`（不写就用兜底文案）。

## 五、已知边界（这一版故意没做）

- 判读是关键词匹配，不理解同义改写；`follow` 是写死的，不是现场生成。
- 「大约 N 天」按纯时长折算，不认你的课表与考试周。
- 选「跳过」记为完成，但总结里不区分"做完了"和"跳过了"。
- 跨学科方向目前挂在任何专业下；它们的地基只引到高数/线代/概率/C 语言这一层。
- 语言课只到"知识点 + 第一件"这一层，没有练习判题与代码评测；每块的 `how` 是三条可动手的事，但不是自动判分的题目。
- AI 老师是复制提示词，不是页面内直接对话（直连要用户自带 key，且受跨域限制）。
- 就地搜依赖 B 站公开接口：接口改版、风控、或没网，这个按钮就不可用；此时自动退回搜索入口，不阻塞任何主流程。
- 没有后端：换浏览器/清缓存就清空，靠「导出我的记录」留住。
