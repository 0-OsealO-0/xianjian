# 先见 · 方向先行的学习引擎

一个给学生用的「先看见方向，再决定学什么」的小工具。它把「基础课 → 专业课 → 实习 → 出路」这条路径倒过来：先让你看到这个专业在解决什么问题、有哪些具体方向，再把你手头的一件事摆出来，缺什么补什么。

课程作业原型（东南大学《人工智能通识导论》创意作品），现在做成了一个能跑的东西。

## 现在有什么

- **专业地图**：电子信息类 17 门课 / 6 条方向路；计算机类 12 门课 / 3 条路；另有 4 条跨学科的路（AI+医疗/金融/教育/制造）
- **知识点粒度**：每门课拆成 3–5 个知识点，可以标「学过 / 在学 / 没学」
- **一次只给一件事**：计划不是一张 8 周表，而是按你已学的知识现算的下一步；缺地基就当场插一条「补一块地基」
- **被审查**：每一步做完追一句「为什么成立、哪里可能是错的」，答不上来的地方就是下次要补的
- **去哪学**：17 门人工筛过的 B 站课（带「什么时候看、不要怎么用」）+ 官方文档 + GitHub；起本机服务后可以就地搜 B 站候选
- **留痕**：动手的每一步可以随手写一句，回头能看到自己走到哪了
- **账号与反馈**（可选）：注册后可以留反馈；**只有勾选同意才会上传**，随时可关、可删号

## 跑起来

**线上（国内可直连，无需梯子）**：<https://xianjian-production.up.railway.app/>
- 托管：Railway 免费试用（30 天 / $5 额度），区域 US East
- 数据库：Cloudflare D1（免费、持久），服务端直连 D1 的 HTTP API，所以免费实例重启也不丢数据
- 反馈面板：<https://xianjian-production.up.railway.app/admin.html>（需要 `ADMIN_TOKEN`）
- 为什么不放 Cloudflare Workers：`*.workers.dev` 在国内 DNS 被污染、IP 也不通；`*.vercel.app`、Netlify、Deno、Fly 同样不通

```bash
# 1) 纯静态（不需要任何环境）
双击 大报告/原型/index.html

# 2) 带本机服务（就地搜 + 账号/反馈，本机 SQLite）
双击 大报告/启动服务.cmd
# 或
node 大报告/服务/server.mjs
# 然后打开 http://127.0.0.1:8787/

# 3) 用 D1 当数据层跑在本机（和线上同一套）
CLOUDFLARE_API_TOKEN=… CLOUDFLARE_ACCOUNT_ID=… D1_DATABASE_ID=… node 大报告/服务/server.mjs
```

需要 Node 22+（本机 SQLite 用内置 `node:sqlite`）；线上模式不需要 SQLite，只要 Node 18+ 能跑 fetch。

## 数据与隐私

完整的说明见 [PRIVACY.md](PRIVACY.md)：收什么、不收什么、存多久、怎么删。

- 默认全在浏览器 `localStorage` 里，不上传。
- 起服务并注册后，只有你**显式勾选同意**，才会写入：邮箱、你写的反馈、「完成到第几件事」的计数。
- 不记录 IP、UA、浏览记录、学习内容。
- `DELETE /api/me` 会级联删除该用户的所有记录。
- 反馈面板：`/admin.html`（本机访问免令牌；公网部署请设置 `ADMIN_TOKEN` 环境变量）。

## 目录

```
大报告/
  原型/         前端（纯静态，index.html 双击可用）
    data.js     课程 / 知识点 / 方向 / 资源 / 课程白名单
    majors.js   各专业的课程表与方向（要加专业改这里）
    app.js      流程与任务链
    account.js  账号与反馈（可选层）
    admin.html  反馈面板
  服务/         零依赖 Node 服务（静态 + B 站搜索代理 + 账号/反馈接口）
    server.mjs  入口
    api.mjs     账号 / 反馈 / 管理端
    store.mjs   SQLite 数据层
  项目构想_先见_v0.md   8000 字构想书的底稿
  启动服务.cmd
```
